# Shiny-App-SCS-Winners
This is a simple Shiny app involving the previously cleaned data on Supreme Cat Show winners from Wikipedia.

The first tab is text-only and describes the data for the user. I realized that some of the data, such as the numbered sections, probably doesn't make sense to someone who doesn't already know what it means, so I wrote some descriptions and displayed the whole table.

The second tab is a new graph - a line graph of the number of male vs female winners as they increase over time.

The third tab is a similar graph to the "wins by section" bar chart in the cleaning project, but it's interactive so you can see how it changes by year. Ideally I would have changed the formatting to remove the comma.
